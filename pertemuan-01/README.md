# Pertemuan 1 Pemrogaman Web Dasar
 dokumentasi capaian pembelajaran P1
1. Konsep Dasar Pemrograman Web
Pemrogtaman web adalah proses membuat halaman atau aplikasi yang bisa di akses lewat browser menggunakan teknologi seperti HTML, CSS, JavaScript, PHP, dan MySQL.
2. Arsitektur Klien-Peladen
Arsitektur klien peladen adalah cara kerja dimana klien  meminta data , dan peladen memproses lalu mengirim jawaban nya.
3. HTTP Request dan Response
HTTP Request adalah permintaan yang dikirim klien ke peladen, sedangkan HTTP Response adalah jawaban yang dikirim peladen kembali ke klien.
4. HTML, CSS, JavaScript, PHP, MySQL
HTML untuk struktur, CSS untuk tampilan, JavaScript untuk interaksi, PHP untuk proses di peladen, dan MySQL untuk menyimpan data.
5. Hubungan Antarteknologi
Kelima teknologi ini saling melengkapi, HTML CSS JavaScript di sisi klien, PHP dan MySQL di sisi peladen untuk proses simpan data.
